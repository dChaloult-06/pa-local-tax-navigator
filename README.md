# PA Local Tax Navigator

**A Pennsylvania local payroll tax reference for payroll professionals.**

Built by **Dorothy Chaloult, CPP** — Payroll Tax Compliance & Technology Specialist with 23+ years of experience in Pennsylvania and multi-state payroll tax compliance.

---

## What This Tool Covers

Pennsylvania has one of the most complex local tax systems in the United States — 2,500+ jurisdictions, 69 Tax Collection Districts, multiple special-rule cities, and cross-border interaction with neighboring states that most reference materials get wrong.

This tool provides:

| Section | Coverage |
|---|---|
| **Act 32 / EIT** | Higher-Of rule, PSD codes, Residency Certification Form, employer setup checklist |
| **Local Services Tax (LST)** | Rates, proration by pay frequency, low-income exemption, concurrent employment rules |
| **Philadelphia Wage Tax** | Current rates, 4 residency scenarios, Act 48, convenience-of-employer doctrine, out-of-state employees |
| **Pittsburgh Special Rules** | EIT rates, LST structure, Payroll Expense Tax, Allegheny County TCD structure |
| **Out-of-State Employees** | 880000 PSD code, Scenario 1 (out-of-state resident / PA worksite), Scenario 2 (PA resident / out-of-state employer) |
| **PA–Maryland Deep Dive** | York/Adams 1981 legal settlement, TCD-level local exemption, the "tit-for-tat" mechanism, Form 515 trigger, MD Form 502CR |
| **Tax Collectors** | Major collector directory with employer portal links |

## How to Publish on GitHub Pages

### Step 1 — Create a GitHub Account
If you don't already have one:
1. Go to [github.com](https://github.com)
2. Click **Sign up** and complete email verification

### Step 2 — Create a New Repository
1. Click the **+** icon → **New repository**
2. Name it: `pa-local-tax-navigator`
3. Set visibility to **Public**
4. Check **"Add a README file"**
5. Click **Create repository**

### Step 3 — Upload Your Files
1. In your repository, click **Add file** → **Upload files**
2. Upload `index.html`, `README.md`, and `LICENSE`
3. Click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Click **Settings** → **Pages** (left sidebar)
2. Under **Source**, select **Deploy from a branch**
3. Branch: **main** / Folder: **/ (root)**
4. Click **Save**
5. Wait 1–2 minutes → your site will be live

## How to Update Content

When rates change (Philadelphia updates July 1 annually; other jurisdictions vary):

1. Go to your repository on github.com
2. Click `index.html`
3. Click the **pencil icon** (Edit this file)
4. Search for the rate you need to update (`Ctrl+F` in the edit view)
5. Make your changes
6. Click **Commit changes**

Your live site updates automatically within 1–2 minutes.

## Key Design Decisions

- **Single HTML file** — no dependencies, no build process, no server required. Works directly from GitHub Pages.
- **No third-party company references** — all guidance is drawn from official government sources (DCED, PA DOR, Philadelphia DOR, Maryland Comptroller, individual TCD collector publications)
- **Verified sourcing** — every compliance rule is traceable to an official government FAQ, statute, or collector guidance document
- **PA–MD exemption accuracy** — the York/Adams County exemption is documented via the York Adams Tax Bureau's own published guidance; the broader TCD exemption list is acknowledged as requiring worksite-level verification with individual collectors
